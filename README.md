# Thawbi React docs

Documentation of the Thawbi (ثوبي) React theme for Salla stores, in Arabic and English, and the home blocks'
editor thumbnails (`docs/public/block-previews/`).

Live site: https://amasmoudi90.github.io/anaqa-react-docs/

```bash
npm install
npm run dev     # local preview
npm run build   # static site in docs/.vitepress/dist
```

Every push to `main` publishes the site through GitHub Pages (`.github/workflows/deploy.yml`).
