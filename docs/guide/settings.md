# إعدادات الثيم

تجد الإعدادات في لوحة سلة: **المظهر ← تخصيص الثيم ← إعدادات الثيم**. الألوان والخط يُختاران من إعدادات سلة نفسها (لون المتجر وخطه)، وثوبي يستخدمهما في الأزرار والروابط عند الحاجة.

## بطاقة المنتج

| الإعداد | ما يفعله |
|---|---|
| شكل بطاقة المنتج | عمودية (الصورة فوق الاسم) أو أفقية |
| شكل صورة بطاقة المنتج | حسب الصورة، مربعة، عرضية أو طولية. صور الملابس طولية عادة، فيبدأ الإطار بنسبة ٤:٥ |
| إظهار زر «أعلمني عند التوفر» | يظهر على بطاقة المنتج النافد بدل زر الإضافة |

## هوية ثوبي

| الإعداد | ما يفعله |
|---|---|
| خطوط ثوبي للصفحات الإنجليزية | خط لاتيني يناسب التصميم في الصفحات الإنجليزية؛ العربية تبقى بخط متجرك |
| لون الأزرار | أسود (كما في التصميم) أو لون متجرك |
| الوضع الافتراضي | فاتح أو داكن أو حسب جهاز الزائر |
| زر تبديل الوضع | زر قمر/شمس في رأس الصفحة يتيح للزائر التبديل |

## رأس الصفحة

| الإعداد | ما يفعله |
|---|---|
| شريط الإعلانات | شريط رفيع أعلى الصفحة برسائل تتبدل (رسائلك، والتبديل التلقائي كل ٥ ثوانٍ) |
| اختيار اللغة والعملة في الشريط | يظهر فقط إن كان متجرك يقدّم أكثر من لغة أو عملة |
| روابط التواصل في الشريط | أيقونات حساباتك من بيانات المتجر |
| تثبيت شريط القائمة | يبقى رأس الصفحة ظاهراً عند التمرير |
| شريط شفاف فوق الواجهة الرئيسية | يظهر رأس الصفحة شفافاً فوق عنصر «الواجهة بالبطاقات» حين يكون أول عنصر |
| كلمتا «تسجيل الدخول» و«السلة» | بجانب الأيقونات على الشاشات الكبيرة |
| شعار فاتح لرأس الصفحة | يُستخدم فوق الواجهة الداكنة والوضع الداكن إن كان شعارك داكناً |
| شريط التنقل السفلي في الجوال | شريط تنقل ثابت أسفل الشاشة (متوقف افتراضياً، فرأس الصفحة في الجوال فيه القائمة والبحث والحساب والسلة) |
| القائمة الرئيسية في سطر واحد | ما لا يتسع يذهب إلى قائمة «المزيد» |

## الصفحة الرئيسية

| الإعداد | ما يفعله |
|---|---|
| طريقة عرض الصور في قسم قائمة عناصر | تغطية المساحة أو إظهار الصورة كاملة (لعناصر سلة الأساسية) |
| وضع عمودي للمنتجات الثابتة | لعنصر «منتجات ثابتة» من سلة |
| زر «الكل» في الصفحة الرئيسية | يظهر رابط «عرض الكل» في عناصر سلة الأساسية |

## أسفل الصفحة

| الإعداد | ما يفعله |
|---|---|
| أسفل الصفحة داكن | خلفية داكنة متوهجة، أو فاتحة |
| لون توهج الخلفية | اللون في وسط الخلفية الداكنة |
| شعار أسفل الصفحة | شعار مختلف للخلفية الداكنة (اختياري) |
| عنوان الدعوة، نصها، نص الزر | دعوة لإنشاء حساب: يفتح الزر نافذة التسجيل للزوار ويقود العملاء إلى حسابهم |
| عنوانا عمودي الروابط | عمود «تسوّق» (من القائمة الرئيسية) وعمود «روابط مهمة» (من قائمة أسفل الصفحة) |
| العنوان | يظهر مع هاتف المتجر وبريده (سلة لا ترسل العنوان للثيم) |
| شريط المزايا | حتى ٤ مزايا بأيقونات فوق أسفل الصفحة |
| زر العودة للأعلى | زر دائري يظهر عند التمرير |

## صفحة المنتج

| الإعداد | ما يفعله |
|---|---|
| مسار التنقل | في صفحة المنتج وصفحة قائمة المنتجات |
| زر طرح سؤال | يفتح محادثة واتساب المتجر (أو البريد) ومعها اسم المنتج |
| مميزات المتجر تحت زر الإضافة | سطر لكل ميزة |
| نص تبويب الشحن والاسترجاع | يظهر في تبويب مستقل |
| إشعار الإضافة للسلة المحسن | نافذة صغيرة بعد الإضافة مع رابط السلة |
| تثبيت زر الإضافة أسفل شاشة الجوال | الكمية وزر الإضافة ثابتان أسفل الشاشة |
| خيارات المنتج في لوحة قابلة للطي | للمنتجات ذات الخيارات الكثيرة |
| الخيارات النصية كأزرار | المقاسات مثلاً تظهر أزراراً بدل قائمة منسدلة |
| إظهار الوسوم | وسوم المنتج كروابط |
| طريقة عرض صور المنتج، تكبير الصور | تغطية الإطار أو إظهار الصورة كاملة، والتكبير عند المرور |
| طرق الدفع تحت زر الإضافة | شعارات طرق الدفع المفعّلة في متجرك |
| الأسئلة الشائعة تحت المنتج | عنوان وصورة وأسئلتك وأجوبتها |
