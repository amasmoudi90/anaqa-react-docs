# Changelog

## 1.0.0

First release of Thawbi:

- 29 home page blocks, and a ready-made home page before any block is added.
- Thawbi's own product card and a product page made for fashion (size buttons, tabs, FAQ, pinned bar on phones).
- A header that sits transparent over the hero, search, a mega menu with photos, and a dark glowing footer.
- Cart, blog, brands, static, account and 404 pages in Thawbi's look.
- Arabic and English, light and dark mode.
