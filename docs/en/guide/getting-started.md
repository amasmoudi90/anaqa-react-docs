# Getting started

## 1. Install the theme

In the Salla dashboard: **Appearance → Theme store**, find **Thawbi**, install and activate it. A complete home page
shows right away, before you add any block.

## 2. Identity

1. **Settings → Store settings**: logo, store colour, font.
2. **Theme settings → Thawbi identity**: button colour (black or your store colour), default mode (light or dark), and
   the mode switch.
3. If your logo is dark, add a **light header logo** for the dark hero and dark mode.

## 3. Menus

- The **main menu** shows in the header and in the footer's "Shop" column. Sub-categories with photos open a photo
  panel on hover.
- The **footer menu** shows in the "Useful links" column: put your shipping, returns and privacy pages there.

## 4. Home page

Open **Appearance → Customize theme → Home page** and add "Thawbi:" blocks. Start with the **hover-card hero** at the
top, then **products** and **category cards**. See [Home page blocks](./home-blocks).

Pick photos from the editor's **media gallery** so they are saved with the block.

## 5. Products

- Portrait clothing photos (for example 800×1000) look best on the card.
- Add sizes and colours as product options; they show as buttons and colour dots.
- Turn on Salla's **size guide** so its link shows on the product page.
- Write the **shipping and returns** text in the theme settings for its product page tab.

## 6. Check

Try the store on a phone, in light and dark mode, and in English if you enabled it.
