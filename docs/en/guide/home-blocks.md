# Home page blocks

Thawbi adds 29 blocks to Salla's editor (named "Thawbi: …"). Each starts with default texts and photos you can replace; the Arabic defaults read in English on English pages until you change them. Add the same block more than once if you need to.

## The ready-made home page

While the home page has no blocks, Thawbi shows a complete page in this order: hover-card hero, trending this week, countdown offer, category cards, collection tabs (list), about us, tabbed products, video story, featured product, collection tabs (tiles), customer reviews, shop the look, why us, blog, community gallery. Once you add a block, only your own blocks show.

## The blocks

### Thawbi: hero with cards

![Thawbi: hero with cards](/block-previews/thawbi-hero-cards.jpg)

A first screen: a dark panel beside tall photo cards that widen on hover.

**Settings:** Title, text, button and link, glow colour, 2–4 cards (photo, title, line, button, link, colour).

### Thawbi: products

![Thawbi: products](/block-previews/thawbi-products.jpg)

Products from a source you choose, as a grid or a slider.

**Settings:** Title, line, source (newest, offers, best selling, top rated, categories, picked products in your order), count, layout, "View all" button.

### Thawbi: countdown offer

![Thawbi: countdown offer](/block-previews/thawbi-countdown.jpg)

A limited-time offer with a countdown and a cut-out photo.

**Settings:** Title, text, end date, hide when ended, button, transparent PNG, glow colour.

### Thawbi: category cards

Tall category cards with photos.

**Settings:** Title, line, categories in your order (or the first ones with a photo), count, "View all" button.

### Thawbi: collection tabs

**Settings:** Look, title, text, button text, product count, tabs (category and icon), panel colour.

### Thawbi: about us

## Notes

- Salla has no newsletter list for themes, so the sign-up block opens the sign-up window for guests and links customers to their account.
- The coupon block shows the code you type; create the coupon itself in the Salla dashboard first.
- Google Maps and the videos load only when a visitor clicks, so the home page stays fast.
- The video story and videos blocks have no default video; add a YouTube or MP4 link.
- Salla's editor keeps an image when you pick it from the media gallery.
