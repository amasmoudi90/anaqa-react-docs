# Theme settings

Find them in the Salla dashboard: **Appearance → Customize theme → Theme settings**. Colours and the font come from
Salla's own settings (your store colour and font); Thawbi uses them for buttons and links where it fits.

## Product card

| Setting | What it does |
|---|---|
| Product card layout | Vertical (photo above the name) or horizontal |
| Product card image shape | As the photo, square, landscape or portrait. Clothing photos are usually portrait, so the frame starts at 4:5 |
| "Notify me when available" button | Shown on sold-out cards instead of the add button |

## Thawbi identity

| Setting | What it does |
|---|---|
| Thawbi fonts for English pages | A Latin font that suits the design on English pages; Arabic keeps your store font |
| Button colour | Black (as designed) or your store colour |
| Default mode | Light, dark, or the visitor's device setting |
| Mode switch | A moon/sun button in the header so visitors can switch |

## Header

| Setting | What it does |
|---|---|
| Announcement bar | A thin bar at the top with rotating messages (your messages, autoplay every 5 seconds) |
| Language and currency in the bar | Shown only when the store offers more than one |
| Social links in the bar | Your accounts from the store's details |
| Sticky menu bar | The header stays visible while scrolling |
| Transparent bar over the hero | The header sits transparent over the "hover-card hero" when it is the first block |
| "Sign in" and "Cart" labels | Next to the icons on large screens |
| Light header logo | Used over the dark hero and in dark mode if your logo is dark |
| Phone bottom bar | A navigation bar pinned at the bottom (off by default: the phone header already has the menu, search, account and cart) |
| Main menu on one line | Items that don't fit go into a "More" menu |

## Home page

| Setting | What it does |
|---|---|
| Image fit in the items list | Cover or show the whole photo (Salla's own blocks) |
| Vertical fixed products | For Salla's "fixed products" block |
| "All" button on the home page | Shows "View all" on Salla's own blocks |

## Footer

| Setting | What it does |
|---|---|
| Dark footer | A dark glowing background, or light |
| Glow colour | The colour in the middle of the dark background |
| Footer logo | A different logo for the dark background (optional) |
| Call-to-action title, text, button | An invitation to create an account: opens the sign-up window for guests, the account for customers |
| Link column titles | "Shop" (from the main menu) and "Useful links" (from the footer menu) |
| Address | Shown with the store's phone and email (Salla doesn't send the address to themes) |
| Features bar | Up to 4 promises with icons above the footer |
| Back to top | A round button that shows while scrolling |

## Product page

| Setting | What it does |
|---|---|
| Breadcrumbs | On the product page and product lists |
| Ask a question | Opens a chat with the store's WhatsApp (or email) with the product's name |
| Store promises under the add button | One line per promise |
| Shipping and returns tab text | Shown in its own tab |
| Improved add-to-cart notice | A small window after adding, with a link to the cart |
| Pinned add bar on phones | Quantity and add button pinned at the bottom |
| Collapsible product options | For products with many options |
| Text options as buttons | Sizes, for example, show as buttons instead of a dropdown |
| Show tags | Product tags as links |
| Product photo fit, zoom | Cover the frame or show the whole photo, and zoom on hover |
| Payment methods under the add button | The payment methods enabled in your store |
| FAQ under the product | A title, a photo, and your questions and answers |
