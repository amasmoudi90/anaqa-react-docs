# FAQ

### Why does a full home page show when I haven't added blocks?
Thawbi shows a ready-made page while the home page is empty. Once you add a block, only your blocks show.

### I picked a photo and it disappeared after saving.
Pick it from the editor's media gallery; Salla's editor keeps photos chosen from the gallery.

### Why doesn't the button show on my slide or banner?
A button shows when both its text and its link are set. A banner with a link and no button text becomes a link.

### Is there a newsletter sign-up?
Salla has no newsletter list for themes. The sign-up block and the footer invitation open Salla's sign-up window.

### Product counts don't show on category cards.
They show only when Salla sends the count with the categories.

### How do I add a video?
In "video story" and "videos", paste a YouTube link or a direct link to an MP4 file.

### Why are buttons black instead of my store colour?
Choose "store colour" in the **button colour** setting.

### Does the coupon in the block work by itself?
The block shows the code and lets visitors copy it. Create a coupon with the same code under **Marketing → Coupons**
in Salla.
