# سجل التحديثات

## ١.٠.٠

الإصدار الأول من ثوبي:

- ٢٩ عنصراً للصفحة الرئيسية، وصفحة رئيسية جاهزة قبل إضافة العناصر.
- بطاقة منتج خاصة بثوبي، وصفحة منتج للأزياء (أزرار المقاسات، تبويبات، أسئلة شائعة، زر ثابت في الجوال).
- رأس صفحة شفاف فوق الواجهة، بحث، قائمة كبيرة بالصور، وفوتر داكن متوهج.
- صفحات السلة والمدونة والماركات والصفحات التعريفية والحساب و٤٠٤ بتصميم ثوبي.
- العربية والإنجليزية، الوضع الفاتح والداكن.
