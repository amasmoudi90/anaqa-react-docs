# الدعم والتواصل

للأسئلة والمشكلات المتعلقة بثيم ثوبي، تواصل معنا عبر صفحة الثيم في متجر ثيمات سلة.

قبل التواصل، اطّلع على [الأسئلة الشائعة](./guide/faq) و[إعدادات الثيم](./guide/settings).

عند الإبلاغ عن مشكلة، أرسل رابط متجرك، والصفحة التي تظهر فيها، ونوع الجهاز والمتصفح، وصورة للشاشة إن أمكن.
